# Product: Awaaz Kit

Awaaz Kit is an open-source, offline-first starter framework for voice-first business workflows in Hindi, Hinglish and English. It is the Skeleton Crew entry for Kiroween 2026. One shared engine (pnpm workspace packages) powers exactly two installable PWAs.

## Scope freeze

Exactly two applications live under `apps/`. Do not add a third.

- `apps/order-awaaz` (Order Awaaz): a spoken or typed customer shopping request becomes a reviewable, confirmed order. Saffron accent, served at `/order/`.
- `apps/bill-awaaz` (Bill Awaaz): a spoken or typed billing instruction becomes an editable, confirmed cash memo / receipt with exact totals. Served at `/bill/`.

Both apps share one IndexedDB database (`awaaz-kit`), one catalog and one Speech_Model cache when deployed on the same origin. The hub page at `/` is generated by `scripts/build-hub.mjs`; it is not an app.

## Core loop

1. User records audio or types an utterance (typed input is first-class, never a degraded mode).
2. A replaceable local speech-to-text provider produces an editable transcript. Raw_Transcript is kept separately from the edited Transcript.
3. A deterministic normalizer and parser extract typed draft lines. No cloud LLM.
4. The catalog matcher resolves products. The uncertainty gate marks missing, ambiguous or unmatched fields.
5. The user reviews and explicitly confirms.
6. The record and an outbox Mutation are committed atomically to IndexedDB (Dexie).
7. If the user opted in, signed in and is online, the outbox syncs idempotently to Appwrite (Cloud or self-hosted).

## Speech provider status

The shipping default provider id is `scripted` (typed input plus chips labelled "Sample"). Shruti (browser ONNX) is built behind `SpeechToTextProvider` and becomes the default only after the manual spike results are recorded in `docs/model-benchmark.md`. Fallback chain: `shruti`, then `whisper-wasm`, then typed input and scripted clips. Never claim on-device voice accuracy that the benchmark does not support.

## Non-goals (do not build)

- Kisan Awaaz, mandi prices, weather or agriculture advisory
- Real missed-call, IVR or telephony
- Payment gateway, UPI, wallet or settlement
- Automatic WhatsApp sending
- Formal GST invoicing, GST filing or accounting integrations. Receipts are titled "Cash memo / receipt" and make no GST claims.
- Predictive inventory, supplier purchasing, multi-branch stock, payroll
- Any cloud LLM dependency in the core loop
- Any third application
- P1/P2 items: catalog editor, sync history panel, benchmark page, CSV import, multi-device conflict resolution, Kiro Crew app, extra language packs

## Demo data

The Demo_Shop ("Sharma Kirana (Demo)") is seeded locally with fixed UUIDs, 24 products with Hindi, Hinglish and English aliases and 5 fictional customers. It can be reset from the About screen. All demo content is clearly labelled fictional.

## UI conventions

- Mobile-first, readable on a small Android phone (360px), 44px touch targets, visible focus, reduced-motion respected.
- UI labels are English; example content is Hindi, Hinglish and English.
- Every status is conveyed by text plus icon, never colour alone.
